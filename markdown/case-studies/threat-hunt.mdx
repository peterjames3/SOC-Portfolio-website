# KC7 Cybersecurity Challenge — Incident Investigation Report

> **Operation: Valdorian Times**
> Analyst: Kamau James Kimani | Date: April 2026 | Classification: Training / Practice /

---

## Executive Summary

The Valdorian Times, a reputable newspaper, published a falsified article accusing mayoral candidate Luffy of corruption and environmental misconduct, just before a major election. The article was not the version approved by Editorial Director Nene Leaks, indicating a deliberate system compromise.

This investigation traces how the attacker gained initial access, established persistence, moved laterally to compromise a second account, and ultimately used that access to send a fraudulent email that resulted in the false article being published.

<Callout type="key">
  **KEY FINDING:** The attack was a two-stage phishing campaign targeting Sonia
  Gose and Ronnie McLovin. The attacker used malicious Word documents to drop
  PowerShell payloads, establish reverse SSH tunnels via plink.exe, and gain
  persistent RDP access — ultimately using Ronnie's compromised account to send
  the fake article to the printer.
</Callout>

### 3.6 Reverse SSH Tunnel — plink.exe

Since the PowerShell script contained plink.exe, which I initially did not know the purpose of, a quick google search debunked that plink.exe (PuTTY command-line SSH client) is a command-line **SSH**, **Telnet**, and **Rlogin** client developed as part of the **PuTTY** suitr by Simon Tatham.
It enables automated, non-interactive conncections to remote servers, making it ideal for scripting tasks like file transfer,remote command execution, and SSH tunnelling from Windows.In this case, it was forwarding RDP port 3389 from the attacker’s remote server back to Sonia’s local machine, giving the attacker persistent remote desktop access.

From here I had to check the presense of the plink.exe that was downloaded by the script in the previous step. I pivoted my research to the **ProcessEvents** and since I had the username of the infected machine O only needed to apply the filter:
`process_commandline contains “plink.exe”`

```kql
ProcessEvents
| where username == "sogose" and process_commandline contains "plink.exe"
```

![Filtering for plink.exe](/plink-execution.png)

| Field              | Value                                   |
| ------------------ | --------------------------------------- |
| **Tool**           | plink.exe (PuTTY suite)                 |
| **Tunnel Type**    | Reverse SSH (-R flag)                   |
| **Port Forwarded** | 3389 → 3389 (RDP)                       |
| **Attacker User**  | $had0w                                  |
| **Password**       | thruthW!llS3tUfree (found in plaintext) |

Basically, the command creates a tunnel that forwards connections from port **3389** (default port for RDP) on the remote server to port 3389 on the local machine.

### 3.7 Post-Compromise Discovery Commands

With RDP access established, the attacker ran a series of discovery commands via cmd.exe to enumerate the compromised environment before lateral movement.
To hunt for this command I needed to filter for the parent process name that contained `cmd.exe` and then analyze process command line field.

```kql
ProcessEvents
| where hostname == "UL0M-MACHINE"
| where process_parent_name contains "cmd.exe"
```

Through the above approach I managed to those commands.

## Section 4 — Phase 2: Lateral Target — Ronnie McLovin

The attacker's ultimate goal was to send a fraudulent article using an insider account. After gaining access via Sonia, the attacker targeted Editorial Intern Ronnie McLovin — the person responsible for sending final article drafts to the printer.

```kql
Email
| where sender has "valdorias_best_recruiter@gmail.com" and recipient has "ronnie_mclovin@valdoriantimes.news"
```

### 4.1 Phishing Email to Ronnie

The email had a link from **promotionrecruit.org** and the subject had some essence of urgency.

| Field            | Value                                                                |
| ---------------- | -------------------------------------------------------------------- |

### 4.2 Confirming the Click

At around 8:55:07 on 2024-01-10 and outbound connection matching the same link was observed on the network making a **`GET`** request with **`src-ip: 10.10.0.19`** and **`user-agent: Mozilla/5.0 (Windows NT 6.1) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/83.0.4103.106 Safari/537.36`**. ## Section 7 — Query Reference (KQL)

### Employee Lookups

```kql
Employees | count
Employees | where role == "Editorial Director"
Employees | where name == "Sonia Gose"
Employees | where role == "Editorial Intern"
```

### Email Analysis

```kql
Email | where recipient == "nene_leaks@valdoriantimes.news" | count
Email | where recipient has "clark_kent@valdoriantimes.news"
Email | where sender has "valdorias_best_recruiter@gmail.com"
Email | where sender has "valdorias_best_recruiter@gmail.com"
| and recipient has "ronnie_mclovin@valdoriantimes.news"
```

### Network Events

```kql
OutboundNetworkEvents | where src_ip == "10.10.0.3"
| and url == "https://promotionrecruit.com/published/Valdorian_Times_Editorial_Offer_Letter.docx"
OutboundNetworkEvents | where url has "https://promotionrecruit.org/share/Editorial_J0b_Openings_2024.docx"
OutboundNetworkEvents | where src_ip == "10.10.0.22" | distinct url | count
```

### File Creation Events

```kql
FileCreationEvents | where hostname == "UL0M-MACHINE"
| and filename == "Valdorian_Times_Editorial_Offer_Letter.docx"
FileCreationEvents | where filename has "Editorial_J0b_Openings_2024.docx"
| and hostname has "A37A-DESKTOP"
```

### Process Events

```kql
ProcessEvents | where hostname == "UL0M-MACHINE" and username == "sogose"
| and process_commandline contains ".ps1"
ProcessEvents | where username == "sogose"
| and process_commandline contains "plink.exe"
ProcessEvents | where hostname == "UL0M-MACHINE"
| where process_parent_name contains "cmd.exe"
```

### Multi-Table Pivot (let variable)

```kql
let mary_ips =
Employees | where name has "Mary" | distinct ip_addr;
OutboundNetworkEvents | where src_ip in (mary_ips) | count

let mary_users = Employees | where name has "Mary" | distinct username;
AuthenticationEvents | where username in (mary_users) | count
```
